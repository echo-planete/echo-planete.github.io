# L'Écho de la Planète — site de Valentin BRIEND

Ce dossier contient un mini-site statique prêt à publier avec GitHub Pages.

## Contenu
- `index.html` : page du journal.
- `assets/plage-polluee.png` : illustration créée pour l'article.

## Publier sur GitHub Pages
1. Connecte-toi à GitHub et crée un nouveau dépôt (repository), par exemple `echo-de-la-planete`.
2. Ajoute `index.html` à la racine du dépôt.
3. Ajoute le dossier `assets` avec l'image `plage-polluee.png`.
4. Ouvre **Settings → Pages**.
5. Dans **Build and deployment**, choisis **Deploy from a branch**.
6. Sélectionne la branche `main` et le dossier `/ (root)`, puis enregistre.
7. Attends la publication : GitHub affichera l'adresse publique du site dans la section Pages.

Le site est responsive (ordinateur et téléphone) et ne nécessite aucun outil de compilation.

## À vérifier avant publication
- Vérifie les liens des sources.
- Demande l'autorisation de ton professeur ou d'un parent si nécessaire avant de publier un travail scolaire publiquement.
- L'image est une illustration générée, et non une photographie documentaire d'un lieu réel.
